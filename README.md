## 🚀 About Me

I'm a **Senior Data Engineer at Paramount Global** on the **Data Intelligence Group (DIG)**, building streaming data pipelines, real-time analytics, and ML-driven systems that power content, advertising, and viewership intelligence across the company's streaming platforms.

I'm a builder at heart — I like turning gnarly data problems into clean, observable, production-grade systems. Recently that's looked like real-time event pipelines for live sports, GenAI-driven content metadata generation, and agentic data engineering tooling.

> *"Pipelines should be boring. The insights they unlock shouldn't be."*

## 🏆 Featured Work

### 🌞 [SolarWind_Prediction](https://github.com/Gupta-Anit/SolarWind_Prediction)
Deep learning models (2-layer and 3-layer ConvLSTM, up to 2048-node architectures) predicting solar wind MHD parameters at 1 AU from heliospheric simulation data (Predictive Science Inc.). Includes data extraction, frame correlation analysis, and augmentation pipelines.

### 🛒 [HackGT 2019 — Predictive Analytics for Store Managers](https://github.com/Gupta-Anit/Predictive-Analytical-tools-for-Store-Managers--HackGT-2019)
Time-series forecasting tool achieving 89% accuracy on real-time NCR Corporation retail data, providing store managers with sales predictions across product categories.

### 📚 [LSTM Text Summarizer](https://github.com/Gupta-Anit/LSTM-TEXT-SUMMARIZER)
Sequence-to-sequence LSTM model for abstractive text summarization with attention mechanism.

### 🏈 [NFL Playoff Prediction (Monte Carlo)](https://github.com/Gupta-Anit/NFL-Playoff-Prediction-MonteCarlo)
Monte Carlo simulation framework for forecasting NFL playoff outcomes from regular-season statistics.
